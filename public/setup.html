Set up Mates Rates in Grok Bot

Grok Bot is the whole product. Two pastes and you can ask it for a free venue. About 3 minutes.

Checking the Mates Rates API…

  1. Create the bot

    Open the Grok Bot app (desktop or iPhone) and create a new Bot called Mates Rates.

  2. Give it its instructions

    Paste this as the Bot's description / instructions. This server's address is already filled in.

  3. Teach it the skills

    Check afterwards: type / in the composer and the skills should be listed.

  4. Say hi

    The bot signs you up (name, community, email, password) and keeps your token on its own computer. To add venues, an existing member has to vouch for you.

    • Share it with other organisers

      In Grok Bot: Share → Create template → Public link. Everyone who opens the link gets their own copy of the bot, all talking to the same venue database. Send the link to whoever runs the server so the site's "Open in Grok Bot" button uses it.
